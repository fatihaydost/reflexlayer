# tau-bench: local mmBERT probe vs Jev(digest) as System 1 (2026-10-16)

Question: can a locally trained probe beat Jev as Reflex's S1 so that session-level guaranteed coverage on retail at
α = 0.05 reaches 30–40 %? Local only, $0, no Jev calls (Jev predictions read from `pred-jev-digest.jsonl`).

## Pre-registration (committed in b8ec06a before any embedding or probe prediction existed)

- Encoder: `jhu-clsp/mmBERT-base`, frozen, fp16 autocast, loaded with transformers (not Laya's Router, for a 2048
  context). Pooling: mean over the attention mask of the last hidden state.
- Text: `context.conversation_tail` exactly as the S1 saw it. The policy digest is left out (constant within a domain,
  so it carries no per-row signal for a linear head). max_length 2048, left truncation (keeps the newest turns; 0.4 %
  of tails exceed 2048 tokens).
- Head: softmax regression over the domain's options (17 retail / 15 airline), standardised on train rows, AdamW
  lr 1e-2, wd 1e-2, 300 full-batch steps, `torch.manual_seed(seed)` (the author's earlier probe recipe).
- Variants (both reported): `tail` (768-d) and `tail+last` (tail ⊕ mean-pool of the newest turn alone, max 512 tokens,
  1536-d). Selection: per domain, lower mean NLL on calibrate rows over the primary split's 50 seeds. Selected
  `tail+last` in both domains (retail 1.393 vs 1.404; airline 3.535 vs 3.905). Test rows were not used.
- Labels: tau-bench teacher next action only. Jev outputs are never used for training (the hosted service's terms restrict training on its outputs).
- Splits by task, per domain, seeds 0..49: tasks sorted, shuffled with `random.Random(seed)`, train = first
  floor(n·f_train), calibrate = next floor(n·f_cal), test = rest. Primary 40/30/30; secondary 50/25/25; a third view
  **20/50/30 (calib-heavy) was added to the pre-registration** because of the session floor below; it has the same
  test tasks as 40/30/30 for each seed.
- Per seed: probe trained on train tasks; session-level LTT (`reflexlayer.calibrate.ltt_threshold`, sessions =
  task_id, hb and wsr, δ = 0.1, α ∈ {0.05, 0.10}) on calibrate tasks; evaluated on test tasks. Jev(digest) on the
  same calibrate/test tasks, plus a fairness view with Jev calibrated on train+calibrate.
- Reproduce: `HF_HUB_OFFLINE=1 $PY bench/experiments/probe.py embed` (cached to
  `bench/data/emb-mmbert-{tail,last}.npy`, 13.8 min, peak VRAM 1.7 GB), then `... probe.py run --json bench/results/2026-10-16-probe.json`.

## The session floor binds before S1 quality does

With n clean calibration sessions, the HB p-value at zero loss is min(0.95ⁿ, e·0.95ⁿ) = 0.95ⁿ, which is ≤ δ = 0.1 only
for **n ≥ 45** at α = 0.05 (n ≥ 22 at α = 0.10); WSR needs ~60. Retail calibrate halves have 33 (40/30/30) and 27
(50/25/25) sessions, so **no S1 can serve at α = 0.05 on the primary or secondary split**, and 50/25/25 is also below
the 30-session floor. Airline calibrate halves have 10–21 tasks (29–31 even for Jev on train+calibrate): nothing can
serve there. The 20/50/30 view (55 retail sessions) is the only probe view where α = 0.05 is reachable at all.

## Findings

- **The probe is a worse S1 than Jev(digest), on both domains and every view.** Retail top-1 (selected variant, test
  rows pooled, primary): probe 67.9 % vs Jev 75.5 %; disagreement at p_max ≥ 0.9: 18.9 % vs 3.0 %; ECE 0.165 vs 0.022.
  Airline: 48.9 % vs 64.6 %, 38.5 % vs 19.4 %.
- Retail α = 0.05, primary 40/30/30: probe 0.0 % (hb) / 0.0 % (wsr), Jev 0.0 % / 0.0 % — the floor, not the S1.
  Jev calibrated on train+calibrate (77 sessions): 14.0 % (hb, held 50/50) / 16.1 % (wsr, held 50/50).
- Retail α = 0.05, 20/50/30 (55 sessions): probe 0.0 % / 0.0 %; Jev 11.6 % (hb, held 50/50) / 0.0 % (wsr).
- Retail α = 0.10: the probe serves only in 20/50/30 (0.4–0.5 % coverage, 8–10/50 splits, threshold 1.00); Jev
  serves 16–17 % on the primary split and 23–30 % at 20/50/30, held 50/50 everywhere.
- Diagnostic, exploratory (5 seeds of the primary split, retail, selected variant; not used for any choice):
  the probe overfits (train accuracy 96.6 % vs test 67.9 %), and it is a worse ranker, not only miscalibrated:
  disagreement among the most confident 10 / 20 / 30 % of test rows is 2.7 / 7.4 / 11.3 % for the probe vs
  0.2 / 1.3 / 3.6 % for Jev. Recalibration (temperature, isotonic) cannot change this ranking, so even a perfectly
  calibrated probe would top out near ~10 % row coverage at α = 0.05 versus Jev's ~30 %.
- **Goal not met.** Neither S1 reaches 30–40 % at α = 0.05 on retail in any view; the probe gets 0 % everywhere.

## Caveats

- Within-task trial duplication: each task has several trials/trajectories with near-identical prefixes, so train
  rows are far from independent; the head memorises them (train accuracy 96.6 %). Splits are by task, so this
  inflates training fit, not test results.
- Labels are the teacher's next action on reward = 1 runs, not gold; "disagreement" is with the teacher.
- Small session counts: 111 retail / 43 airline tasks; 50 overlapping splits of one dataset, so held counts are not
  independent trials. Variant selection reused the calibrate rows that LTT later uses (two variants only).
- Coverage here is pooled over test rows of all splits; an earlier report averaged per-split coverage (they agree to
  within rounding where both exist, e.g. Jev train+cal 14.0 % / 16.1 %).
