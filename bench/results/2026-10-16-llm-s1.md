# LLM-logprob System 1 on ABCD binary: pilot only, full run not triggered (2026-10-16)

**Hypothesis.** A small instruct LLM read as System 1 (first-token logprobs over option letters, `LogprobLLMAdapter`) separates `button` from `reply` better than Jev (top-1 69.1% random / 67.7% official vs majority 72.6% / 74.1%), so LTT could serve non-trivially.

**Setup.** Pilot data: seed-11 shuffle of whole sessions until >= 200 decisions = 16 sessions, 208 decisions (`bench/data/abcd_binary_pilot200.jsonl`; majority `reply` 73.6%). `--compact` (as the Jev run used), 4 workers, `--budget-usd 0.04` per file. Prompt shape: system "You are a precise classifier."; user = question, lettered options (A/B), dialogue context, "Answer with the single letter of the best option."; `max_tokens` 1, `temperature` 0, `top_logprobs` 20; probabilities = renormalised letter logprobs. Prices actually paid are the `cost` sums below (OpenRouter-reported). Letter mass: not recorded in the prediction rows, not reported.

## Decision rule (pre-registered): outcome

Go to full run only if pilot top-1 > majority on the 200 rows AND <= 5% error rows. Llama: 59.6% < 73.6%, fails. Gemma: 65.9% < 73.6%, fails. Qwen3: 69.5% < 73.4% on ok rows and 26.0% errors, fails both. **No model qualifies; no full run, no LTT evaluation** (so the success bar of LTT hb alpha=0.05 coverage >= 30% and the per-type breakdown were not tested).

## Findings

- None of the three models beats the majority label on the pilot: 59.6%, 65.9%, 69.5% (ok rows) vs 73.6%.
- Gemma matches Jev on the same rows (65.9% vs 65.4%) and is confidently wrong when it speaks: 78.4% of rows have p_max >= 0.9, with 28.2% disagreement there (Jev's 0.9 disagreement was 22.8% on the full file).
- Llama-8B never reaches p_max >= 0.9 (0.0% coverage), so a confidence threshold has nothing to serve.
- Qwen3-235B has the best top-1 on rows it answered (69.5%) but 54 of 208 calls failed (49 HTTP errors, 5 without logprobs), 26.0% against the 5% limit; error rows were billed in 5 cases.
- Cost is small: $0.0000155 to $0.0000315 per decision, so the pilot cost $0.0134 of the $0.50 cap; the blocker is signal, not price.
- Caveats: 208 decisions from 16 sessions (a 95% interval on a 70% accuracy is about +-6 points), one prompt, compact context, no prompt variants tried, no letter-mass check.
