# tau-bench next-action benchmark (2026-10-16)

- Data: tau-bench historical trajectories (reward=1 runs only), 154 tasks (43 airline, 111 retail), 14,866 decisions, MIT licence. Successful trajectories per task: 1 to 12 (median 8.5), from two teacher models: Sonnet-3.5-new (10,251 decisions) and GPT-4o (4,615 decisions).
- Label: the teacher's next action on a verified-successful run (not gold). Options: 15 (airline) / 17 (retail).
- Split: by task (50 overlapping splits), delta = 0.1; LTT = learn-then-test threshold selection.
- Jev (`typesafe/jev-1.13`, OpenRouter): total spend $1.2374, median 319 ms per call (8 workers), 0 errors.
- Laya (`multilingual`, local RTX 3050, run with `--compact` input): $0, median 199 ms per call (4 workers, calls queue behind the server lock; ~48 ms/decision throughput), 0 errors, no CPU fallback in the server log.
- Majority baseline (always "respond"): 46.2% airline / 45.5% retail. Jev top-1 agreement is 64.0% / 74.5%; Laya's is 8.7% / 10.4%.
- Laya scored far below the majority baseline while being confident (median p_max 1.00). It ran with `--compact` input (options cut to 60 chars, last 1,800 chars of context), so model weakness and input truncation are not separated; no claim about the cause.

## Findings

- Hand-picked "trust p_max >= 0.9" on Jev disagrees with the teacher on 15.6% (airline) / 6.6% (retail) of served decisions (pooled).
- On Laya, fixed thresholds serve about 68-82% of decisions at about 90% disagreement; LTT abstains everywhere, so the guard works.
- Retail, alpha = 0.05: LTT picked a threshold on its own in every split (0.93-0.97, mean 0.95) and matched the best hand-picked threshold (LTT: 26.5% coverage, 3.8% disagreement; fixed 0.95: 26.9% coverage, 3.7%). It held the budget in 45/50 splits.
- Airline: LTT did not hold its budget when it served (alpha = 0.05: 0/21 held when serving; alpha = 0.10: 16/32). Diagnosis is within-task correlation: one task (airline:44) holds 10 of the 15 disagreements at p_max >= 0.98, and all 21 serving splits at alpha = 0.05 had airline:44 in the test half (LTT never served when it was in the calibration half).
- alpha = 0.02 is effectively unservable at this data size: held when serving 0/3 (airline) and 0/8 (retail), and LTT abstains in 94% / 84% of splits.
- Many retail high-confidence disagreements are write actions: of 291 disagreements at p_max >= 0.9, 158 are S1 choosing return/cancel/modify/exchange, and in 140 of those the teacher replied to the user (presumably to confirm first). These are the dangerous ones.

Notes

- LTT bounds the population disagreement with probability >= 1-δ over calibration draws (δ = 0.1). It does not promise every test half is <= α: a threshold whose true risk sits just under α will exceed α on a finite test half fairly often.
- LTT's binomial test treats rows as independent, but rows within a task are correlated, so the guarantee is approximate here (see Findings).
- Threshold columns average splits where a threshold was found; disagreement figures (pooled, p10–p90, held when serving) use serving splits only; coverage averages all splits (no threshold counts as 0).
- held when serving = held/serving: among splits with coverage > 0, how many had test disagreement <= α (fixed thresholds have no α). Pooled disagreement = sum of disagreements / sum of served rows over splits.
- Labels are the teacher's next action on verified-successful runs, not gold.
- Splits are by task: 50 overlapping splits over one dataset, so shares are not independent trials.
- The threshold grid is 0.99..0.50 (no 1.0 rung).
